The [SAFECode project](http://safecode.cs.uiuc.edu/) is using LLVM as a framework for [providing memory safety without runtime checks or garbage collection](pubs/2003-05-05-LCTES03-CodeSafety.html). To do this it makes use of LLVM's link-time whole-program analysis capabilities.
