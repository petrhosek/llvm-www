# 2012 European Conference

*   **What**: The second European meeting, the first full conference.
*   **Why**: To get acquainted, learn how LLVM is used, and exchange ideas.
*   **When**: April 12th, 2012 from 12:00 noon to April 13th, 2012 12:00 noon (plus optional afternoon workshops)
*   **Where**: Hotel Russell, 1-8 Russell Square, Bloomsbury, London, WC1B 5BE, UK. ([map](http://maps.google.co.uk/maps?q=Hotel+Russell,+London&hl=en&ll=51.522683,-0.125291&spn=0.005768,0.013937&sll=53.952002,-1.053189&sspn=0.01091,0.027874&oq=hotel+russell&vpsrc=6&hq=Hotel+Russell,&hnear=London,+United+Kingdom&t=m&fll=51.522683,-0.125291&fspn=0.005768,0.013937&z=17))
